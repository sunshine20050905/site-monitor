# 工地人员识别与安全监控系统 — 软件设计方案（桌面端）

**赛事**：中国大学生计算机设计大赛（4C）  
**当前版本**：**桌面工作站**（Tkinter + OpenCV），单机 SQLite；**不包含** Web 浏览器端（可按需后续增加）。

---

## 一、设计目标

1. **业务**：人员建档 → 人脸采集与 LBPH 训练 → 摄像头监控 → 区域权限与安全帽/吸烟检测 → 考勤与违规留痕 → 统计图表。  
2. **工程**：**界面（`imsafe/ui/theme.py`）**、**配置常量（`imsafe/desktop_config.py`）** 与 **业务/监控（`imsafe/desktop_app.py`）** 分离，便于维护与答辩说明。  
3. **监控**：帧采集与检测逻辑保留在 `desktop_app.py` 既有流程中，仅增强顶栏与主题样式，**不改变** `toggle_unified_monitoring`、视频线程与数据库写入语义。

---

## 二、总体架构（单机）

```
run_security_system.py
        │
        ▼
imsafe.desktop_app.SecurityManagementSystem
   ├── imsafe.paths / imsafe.database  （库路径与建表）
   ├── imsafe.desktop_config           （区域、权限等常量）
   ├── imsafe.ui.theme                 （ttk 外观）
   ├── imsafe.ai_framework             （可插拔推理，默认模拟）
   └── OpenCV + Tk 监控主循环
```

---

## 三、技术选型

| 层次 | 技术 | 说明 |
|------|------|------|
| 界面 | Tkinter + ttk | 标准库；`clam` 主题 + 自定义配色。 |
| 监控与视觉 | OpenCV contrib | 摄像头、Haar/LBPH、可选 DNN/ONNX。 |
| 数据 | SQLite | 文件 `security_system.db`，路径 `get_db_path()`。 |
| 报表 | Matplotlib + openpyxl/pandas | 图表与 Excel 导出（桌面端菜单/功能内已有调用）。 |

---

## 四、数据库连接约定

1. **路径**：`imsafe.paths.get_db_path()` → 项目根目录 `security_system.db`。  
2. **初始化**：`SecurityManagementSystem.init_database()` 内 `sqlite3.connect(get_db_path())` + `init_schema`。  
3. **工作目录**：应用启动时 `os.chdir(get_project_root())`，保证 `face_samples/`、`models/` 等相对路径与库内记录一致。

---

## 五、运行说明

见仓库根目录 **`README.md`**：激活虚拟环境后执行 `python run_security_system.py`。

---

## 六、演进（可选）

- 增加浏览器看板时，建议**独立进程**提供 HTTP API，避免与摄像头 Tk 主循环争用资源。  
- 推理层可替换为 ONNX Runtime，无需改动数据库与 UI 分层。
